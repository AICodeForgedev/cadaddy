# CADaddy User Guide

Welcome to CADaddy, a source-available computer-aided design and drafting
application. It runs natively on macOS, Windows, Linux, FreeBSD and the web.

## Guides

- [Getting Started](getting-started.md) — Install, draw your first lines, save
  and plot.
- [Coming from AutoCAD](coming-from-autocad.md) — What is the same, what is
  different, keyboard habits, missing commands.
- [Working with Files](working-with-files.md) — DWG, DXF, .cdy, PDF; the batch
  converter; exchange notes; eTransmit.
- [Sheet Sets and Publishing](sheet-sets-and-publishing.md) — Organise drawings,
  number sheets, publish to PDF.
- [3D, Walk and Plans-to-Model](3d-walk-and-plans-to-model.md) — Solid
  modelling, first-person walkthrough, automated 3D from floor plans.
- [Takeoff](takeoff.md) — Quantity measurement: lengths, areas, counts, CSV
  export.
- [For AI Agents](for-ai-agents.md) — MCP setup in Claude Desktop and Claude
  Code, the tools, safety rails.
- [Command Reference](command-reference.md) — Every command, alias, shortcut and
  parameter (auto-generated).
